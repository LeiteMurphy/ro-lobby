# ADR-01 — Framework web: SvelteKit

- Status: Aceito
- Data: 2026-09-29

## Contexto
A web é a plataforma principal. Os links de lobby circulam no Discord e precisam de
preview. O projeto é solo e tem pouco tempo de desenvolvimento.

## Opções consideradas
- (a) Next.js
- (b) SvelteKit
- (c) Flutter Web

## Decisão
(b) SvelteKit.

## Consequências
- \+ Menos código, e renderização no servidor para os previews.
- − Ecossistema menor que o do React, com menos material de estudo.
